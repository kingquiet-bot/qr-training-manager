# Screenshots

This directory contains screenshots of the QR Training Manager application.

## Required Screenshots

### Desktop (1280×800)
- `01-dashboard-desktop.png` - Main admin dashboard
- `02-create-event-desktop.png` - Create new event form
- `03-event-detail-desktop.png` - Event detail view
- `04-self-checkin-desktop.png` - Self-check-in page

### Mobile (390×844)
- `05-dashboard-mobile.png` - Mobile dashboard view
- `06-scanner-mobile.png` - QR scanner view
- `07-self-checkin-mobile.png` - Mobile self-check-in page

## How to Take Screenshots

Use Chrome DevTools MCP with the following prompts:

### Desktop Screenshots (1280×800)
```text
Use the chrome-devtools MCP. Set the viewport to 1280x800.
Open http://localhost:5000. Take a screenshot and save it as screenshots/01-dashboard-desktop.png.
Then click on "Create New Event" and save screenshots/02-create-event-desktop.png.
```

### Mobile Screenshots (390×844)
```text
Use the chrome-devtools MCP. Set the viewport to 390x844.
Open http://localhost:5000. Take a screenshot and save it as screenshots/05-dashboard-mobile.png.
```

## Notes
- Ensure the app is running on localhost:5000 before taking screenshots
- Use Chrome DevTools MCP for consistent, high-quality screenshots
- Document which resolution was used in the report
