Team ထဲမှာ Personal Proposal တင်ထား Pass ဖြစ်ထားပြီးသားကို အခြား Project  ပြန်ချိန်းလို့ရလားဟင် ဦးလေး
အဲ့ Project က စကို မစရသေးလို့ စထားလက်စရှိတဲ့ Project တစ်ခုနဲ့ ချိန်းမလို့ပါ ဦးလေး၊ မပြီးမှာစိုးလို့

ကျတော်တော့ အဲ့အတိုင်းလုပ်တာ အဆင်ပြေသွားတယ် ဗျ။

ကိုရဲဗျာ အခု ည ၁၂ နာရီတောင် ကျော်နေပြီဆိုတော့ မနက်ဖြန် သင်တန်းအတွက် အချိန်သိပ်မရတော့ဘူး။ Script က WSL ရဲ့ Background Process တွေနဲ့ ငြိပြီး Memory စားသွားလို့ လေးသွားတာ ဖြစ်နိုင်ပါတယ်။

အခုချိန်မှာ Script ကို ထပ်ပြင်ပြီး အချိန်မကုန်ခံတော့ဘဲ၊ **၁၀ဝ% သေချာပေါက် အလုပ်လုပ်နေတဲ့ "သီးသန့်စီ Run တဲ့ နည်းလမ်း" ကိုပဲ ပြန်သုံးလိုက်ကြရအောင်ဗျာ။** ဖုန်းမှာ ကင်မရာပွင့်ဖို့ ပြဿနာကို ဖြေရှင်းဖို့က လွယ်လွယ်လေးပါ။ Terminal (၃) ခု ခွဲဖွင့်ပြီး အောက်ကအတိုင်း တစ်ခုချင်းစီသာ သေချာလေး Run ပေးလိုက်ပါ-

**Terminal (၁) - Web Server အတွက်**

1. Project Folder ထဲသွားပါ။
2. `source venv/bin/activate` လို့ ရိုက်ပြီး venv ဖွင့်ပါ။
3. `python3 app.py` လို့ ရိုက်ပြီး Run ထားလိုက်ပါ။

**Terminal (၂) - Telegram Bot အတွက်**

1. Terminal Tab အသစ်တစ်ခု ဖွင့်ပါ။ Project Folder ထဲ ပြန်သွားပါ။
2. `source venv/bin/activate` လို့ ရိုက်ပြီး venv ဖွင့်ပါ။ (Tab အသစ်ဖြစ်လို့ venv ပြန်ဖွင့်ဖို့ မမေ့ပါနဲ့)
3. `python3 qr_bot.py` လို့ ရိုက်ပြီး Run ထားလိုက်ပါ။

**Terminal (၃) - ကင်မရာပွင့်မယ့် လင့်ခ် (HTTPS) အတွက်**

1. နောက်ထပ် Terminal Tab အသစ်တစ်ခု ထပ်ဖွင့်ပါ။
2. အောက်က Command ကို ရိုက်ထည့်လိုက်ပါ-
```bash
~/.bun/bin/bun x localtunnel --port 5000

```


*(အကယ်၍ ဒီ Command က အလုပ်မလုပ်ရင် `npx localtunnel --port 5000` လို့ ပြောင်းရိုက်ကြည့်ပါ)*

ဒါဆိုရင် Terminal (၃) ကနေ `your url is: https://....` ဆိုတဲ့ လင့်ခ်လေး ထွက်လာပါလိမ့်မယ်။ အဲဒီလင့်ခ်ကို HR ဖုန်းထဲက Browser ကနေ ဝင်လိုက်တာနဲ့ Admin Panel လည်း ပွင့်မယ်၊ **ကင်မရာလည်း သေချာပေါက် ပွင့်သွားပါလိမ့်မယ်။**
